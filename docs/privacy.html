Privacy Policy

Last updated: June 2026 · Applies to autoreach.dev and the AutoReach software

Overview

AutoReach is free, source-available software and can be self-hosted or used with hosted website/API services. Data handling depends on the deployment: self-hosted data is stored by the operator, while hosted endpoints receive the requests and content needed to provide the service. Do not assume data stays on your own device or server when using a hosted endpoint. This policy explains the data flows implemented by the software.

Data We Do Not Collect

The AutoReach project has no access to data in an independently operated self-hosted installation. When using a hosted AutoReach dashboard or API, the service operator may process account details, leads, email text, send logs, and API credentials submitted for delivery. Review the notice provided by the operator of the endpoint you use.

  • Your leads or business contacts
  • Emails you send or receive
  • Your API keys (Google Maps, Groq, Gmail)
  • Your usage statistics or activity
  • Any personal information you enter into the dashboard

Data Stored on Your Server

When you run AutoReach, the following data is stored on your own server or hosting environment:

  • businesses.csv — your lead database (business names, addresses, emails)
  • sent_log.csv — log of emails you have sent
  • followup_log.csv — log of follow-up emails sent
  • autoreach_users.db — user accounts (email addresses, hashed passwords)
  • Environment variables — API keys and credentials you configure

You are responsible for securing this data on your own server.

Third-Party Services

AutoReach integrates with the following third-party services. Their own privacy policies apply when you use them:

  • Google Maps Places API — used to find businesses. Google Privacy Policy
  • Groq AI — used to generate and moderate email content when Groq is configured. Groq Privacy Policy
  • OpenAI Moderation API — optional moderation provider when the operator sets MODERATION_PROVIDER=openai. OpenAI Privacy Policy
  • Gmail (SMTP) — used to send emails. Google Privacy Policy
  • GitHub, Discord, Google OAuth — optional login methods for the mobile app. Standard OAuth flows apply.

Content Moderation Data

AutoReach checks custom templates and prompts when saved, generated email content before it is shown or queued, and email content immediately before sending. The selected moderation provider receives the text being checked. Groq is the default provider; an operator may configure OpenAI or another supported provider. Moderation logs store a SHA-256 content hash and verdict metadata only by default. Setting MODERATION_STORE_EXCERPT=true stores up to 240 characters of the checked text and should be reflected in the operator's privacy notice.

If the moderation provider is temporarily unavailable, AutoReach stores the pending email in an encrypted retry queue so it can be checked before delivery. The encrypted queue payload can contain the email text and the delivery credential needed for a retry. Queue payloads remain stored until database cleanup, including after delivery or resubmission. Operators must set a stable MODERATION_ENCRYPTION_KEY (or SECRET_KEY), secure their database and backups, and establish a retention schedule.

This Website (autoreach.dev)

The autoreach.dev landing page is a static site hosted on GitHub Pages. It does not set cookies, collect personal data, or use analytics. The only third-party content is Google Fonts (loaded for typography).

Cold Email Compliance

AutoReach is a tool for sending cold outreach emails. You are responsible for ensuring your use of AutoReach complies with applicable laws in your jurisdiction, including:

  • GDPR (European Union)
  • CAN-SPAM Act (United States)
  • CASL (Canada)
  • Any other applicable anti-spam or data protection laws

Only contact businesses that may have a legitimate interest in your services, always include an unsubscribe mechanism, and honour opt-out requests promptly.
